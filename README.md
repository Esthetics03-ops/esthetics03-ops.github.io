
# The Esthetics Hub Real-Time Dashboard

## Setup
1. Place GA4 & AdSense OAuth service account JSON in `backend/oauth-credentials.json`.
2. Update `config.json` with real GA4 Property ID & AdSense Account ID.
3. Run `npm install` to install dependencies.
4. Run `npm start` to start backend.
5. Open `index.html` in a browser.
6. Dashboard metrics auto-refresh every 5 seconds.

Optional:
- Set `affiliateApiKey` & `donationsEndpoint` in config.json for extra revenue tracking.
