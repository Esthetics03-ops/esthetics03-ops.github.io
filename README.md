# The Esthetics Hub Auto Sync

This package automates syncing your business info from GitHub to Google Business Profile.

## Setup Steps
1. Go to Google Cloud Console and enable the *Business Profile API*.
2. Replace `config/placeholder.key` with your actual API key.
3. Commit the files to your GitHub repository (main branch).
4. The GitHub Action will automatically sync updates to your Google Business Profile.
